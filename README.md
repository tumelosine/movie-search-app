# Movie Search App
A responsive movie search app built with vanilla JavaScript and the OMDB API.
Search for any movie to see its poster, release year, plot and IMDb rating.

## Screenshot
![Movie Search App showing Avatar search results with posters, plots and ratings](<screenshot.png>)

## Features
- Search movies by name
- Displays poster, year, plot, and IMDb rating
- Skips incomplete results automatically
- Enter key support
- API key protected via config.js

## Tech Stack
- HTML, CSS, JavaScript
- OMDB API

## Setup
1. Clone the repo
2. Copy `config.example.js` to `config.js`
3. Add your OMDB API key (free at https://www.omdbapi.com)
4. Open `index.html` in your browser
